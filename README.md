# 🖥️ PC 1.0.0

**The ultimate Minecraft PvP & performance experience.**

PC is a Fabric-based Minecraft 1.21.11 modpack focused on **PvP, performance, visuals, utility, and customization**. Whether you're fighting, building, exploring, or just trying to get the best FPS possible, PC brings everything together in one pack.

> **LOL BEST ONE YET**

---

## ⚔️ Features

### 🥊 PvP

* PvP-focused resource pack
* Custom crosshair
* Zoom functionality
* Visual effects for combat
* Body Camera shader option
* Optimized gameplay for competitive PvP

### 🚀 Performance

PC includes performance-focused mods to help Minecraft run smoother:

* **Sodium** — Improved rendering performance
* **Iris** — Shader support
* **Voxy** — Enhanced distant-world rendering
* Optimizations designed for smoother gameplay and higher FPS

### 🎨 Visuals & Shaders

Choose from multiple visual experiences:

* **BSL Shaders**
* **Solas Shader**
* **Body Camera**
* Natural Motion Blur
* Iris shader support

Shaders are optional and can be disabled if you want maximum performance.

### 🎙️ Voice Chat

**Simple Voice Chat** provides proximity voice communication.

Talk to players around you naturally without needing external voice-chat software.

### 🛠️ Utility

PC also includes useful tools for everyday Minecraft:

* **WorldEdit**
* **Litematica** *(currently disabled)*
* **Mod Menu**
* **Zoomify**
* **Skin support**
* Fabric API
* Fabric Language Kotlin

## 💻 Requirements

### Recommended

* Minecraft **1.21.11**
* Fabric Loader **0.19.3**
* At least **4 GB RAM**
* A relatively modern GPU
* Java version compatible with Minecraft 1.21.11

### For Shaders

Shaders can significantly increase GPU usage.

If you experience low FPS:

1. Disable shaders.
2. Lower render distance.
3. Lower simulation distance.
4. Disable motion blur.
5. Adjust Sodium's performance settings.

---

## 🎮 Getting Started

1. Install a launcher that supports **`.mrpack`** files.
2. Import **PC 1.0.0**.
3. Make sure the launcher uses:

   * Minecraft **1.21.11**
   * Fabric Loader **0.19.3**
4. Allocate enough RAM.
5. Launch Minecraft.
6. Enjoy!

## ⚠️ Known Information

**Litematica** is included in the pack but is currently **disabled**.

Some shader/resource-pack options are optional and may affect performance depending on your computer.

For the best FPS, use the pack without shaders.
